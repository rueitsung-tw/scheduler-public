## 5. 決策規則

### A. 繼續

勾選條件:

- [ ] 沒有 P0
- [ ] P1 數量可接受，且有明確 workaround
- [ ] 至少完成一輪可閱讀、可匯出的課表
- [ ] 操作人判定結果不是「垃圾」
- [ ] 願意進行下一輪 pilot

**決策: 繼續下一輪 pilot**

建議動作:

1. 保留目前流程
2. 先修 P1 / P2
3. 擴大到更多真實情境驗證

### B. 暫停

勾選條件:

- [ ] 沒有致命 P0，但 P1 過多
- [ ] 操作人勉強能完成流程，但信心不足
- [ ] 課表結果介於「勉強可用」與「不穩定」之間

**決策: 暫停擴大使用，先修高風險問題**

建議動作:

1. 先整理 P1 清單
2. 修完後再做同規模復測
3. 不要急著擴大使用者

### C. 返修

勾選條件:

- [ ] 出現任何 P0
- [ ] 匯出失敗
- [ ] 結果明確被判定為「垃圾」
- [ ] 操作人不願意再用

**決策: 返修 blocker 後再進行下一輪 pilot**

建議動作:

1. 先停下擴大使用
2. 只修 P0 / 關鍵 P1
3. 修完後重跑同一條主線驗證
