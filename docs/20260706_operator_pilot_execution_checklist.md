## 1. 實驗定位

本次是 **單人單機、受控真人操作實驗**，不是公開上線，也不是多人登入協作驗證。

1. 1 位主要操作承辦人（行政組長）

## 3. 建議操作流程

### Phase A：初始化與基本資料確認

- [ ] 進入系統首頁
- [ ] 完成或確認 setup 狀態
- [ ] 檢查學校基本設定是否可閱讀 / 編輯
- [ ] 檢查班級、教師、教室資料是否可正常顯示

### Phase B：需求輸入與資料調整

- [ ] 操作班級需求設定
- [ ] 操作教師設定
- [ ] 操作教室 / 專科教室設定
- [ ] 若有共備或特殊設定，確認可正常保存

### Phase C：排課主流程

- [ ] 執行排課
- [ ] 確認系統有回傳結果
- [ ] 檢查結果頁面是否可閱讀
- [ ] 若操作員需要，進行至少 1 次人工微調或檢視
- [ ] 判斷結果是否屬於「可使用」而非「看似接近但實際不可用」

### Phase D：專科教室與結果閱讀

- [ ] 開啟 Classroom Manager
- [ ] 檢查專科教室分配是否可閱讀
- [ ] 抽查至少 3 個班級的關鍵課程
- [ ] 抽查 alternating / odd-even 呈現是否可理解

### Phase E：匯出

- [ ] 進入 Export Hub
- [ ] 至少完成 1 次 XLSX 匯出
- [ ] 檢查匯出檔案是否可開啟
- [ ] 確認匯出內容與畫面資料大致一致

### Phase F：回饋蒐集

- [ ] 記錄哪一步最卡
- [ ] 記錄哪一段文案最不清楚
- [ ] 記錄有沒有需要技術人員介入的步驟
- [ ] 記錄是否有任何匯出、畫面、資料保存異常

---

## 4. 成功判定

本次 pilot 可視為成功，至少需滿足：

1. 操作員能獨立完成主要流程的大部分步驟
2. 系統能完成至少一輪真實排課與閱讀
3. 至少一種匯出可成功完成
4. 沒有出現阻斷型錯誤導致整個流程無法繼續
5. 操作員主觀判定結果已接近「可拿給校長看」的可用程度

---

## 5. 若出現問題，如何分類

### P0 阻斷

- 無法啟動
- 無法進入系統
- 無法完成排課
- 無法讀取結果
- 無法匯出

### P1 高摩擦

- 能完成，但操作步驟容易卡住
- 文案讓承辦人無法理解
- 需要技術人員頻繁協助

### P2 可延後

- 介面不夠直覺
- 回饋資訊不夠清楚
- 操作上有繞路，但不阻斷
